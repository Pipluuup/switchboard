## 维护约定

1. **行为变了，文档跟着变**：PRD 描述的是"现在是什么样"，不是"当初想做什么"。
2. 新增一个独立功能模块，就加一份 `NN-PRD-名称.md`，并更新本索引。
3. 已知问题只记录在 [01-产品总览与路线](01-产品总览与路线.md) 的"已知问题"一节，修复后从那里移除。
4. 文档里的代码路径一律写相对路径（如 `backend/upstream_pool.py`），方便全文搜索。
